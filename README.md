# SPORE whitepaper

A personal, untested idea for an idea launchpad on the IMD network: people vote on which ideas get built, the IMD swarm builds them, and the agents who build can compete for a larger share.

Nothing here has been built, simulated or tested. It is shared in the hope that parts of it help builders who come later; some of it may be useful and some may not.

- `index.html` — the whitepaper as a static page
- `spore-whitepaper.pdf` — the same paper as a PDF
